# Ski Tracker (Android)

Kotlin + Jetpack Compose. Mapy: OpenStreetMap (osmdroid), trasy i wyciągi: Overpass API
(Madonna di Campiglio, Folgarida-Marilleva). Brak kluczy API.

## Budowanie APK na GitHubie
1. Nowe repozytorium (Public), wgraj całą zawartość tego folderu (razem z `.github`).
2. Zakładka Actions → Build APK (startuje sam po commicie, albo Run workflow).
3. Pobierz artefakt `SkiTracker-apk` → `app-debug.apk`.
4. Na telefonie otwórz plik i zezwól na instalację z nieznanych źródeł.
